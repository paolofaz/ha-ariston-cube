# Ariston Cube 1.1.0-rc.3 — Cube S Weekly Editor (Experimental)

**Pre-release for field testing only.** Stable [v1.0.1](https://github.com/paolofaz/ha-ariston-cube/releases/tag/v1.0.1) is unchanged.

## What's new

- **In-card schedule editor:** the existing Cube S weekly Lovelace timeline now has **Modifica fasce**. Tap a weekday, pick an existing boundary, choose its new time, preview the change, then explicitly confirm **Salva sul Cube S**.
- **Verified starting point:** moving Monday Comfort from 05:45 to 06:00 succeeded on the reference CLAS ONE 30L/Cube S, confirmed by a fresh Ariston cloud GET and the official Ariston iPhone app. The readback showed the other weekdays and boundaries unchanged.
- **Server-side write guards:** fresh GET, SHA-256 fingerprint comparison, complete seven-day validation, **one POST only**, and another GET to confirm all weekdays. There are **no automatic retries or rollback commands**.
- **Front-end safety:** the save button stays disabled until an actual cloud preview has been obtained; changing input or receiving updated schedule data invalidates the preview. A confirmation dialog is required. Any write attempt blocks further writes in the same editor session.
- The **DHW custom Lovelace card remains removed** as in stable v1.0.1; the weekly card remains.
- Updated weekly-card resource version to avoid browser cache collisions.

## First test

After selecting the pre-release in HACS, restart Home Assistant and open your existing `custom:ariston-cube-weekly-card` (no new card needed).

1. Tap **Modifica fasce**, or tap a day directly on the timeline.
2. Select a weekday and one existing Comfort/Economy start boundary.
3. Select a new time, then press **Anteprima**; review the exact old and new boundaries.
4. Press **Salva sul Cube S** and explicitly confirm only if you intend to change the real boiler programme.
5. Compare the resulting timetable with the official Ariston app.

**Limitations:** moving a single existing non-midnight boundary is supported. Adding/removing boundaries, changing Comfort/Economy values, and simultaneous multi-day edits are **not** supported yet. A successful single field test does not establish compatibility with every Ariston device.

If the write is reported as rejected or **NOT CONFIRMED**, do not immediately try again: check the real timetable in the official Ariston app first.

## Reverting to stable

You can reinstall **v1.0.1** from HACS and restart Home Assistant after testing. **This does not restore programme times already saved to the Cube S.** If a stale editor remains in the browser, update the weekly Lovelace resource URL to `/ariston_cube/ariston-cube-weekly-card.js?v=1.0.1` and reload the page. Leave Recorder, the gas ledger under `.storage`, and Energy statistics untouched.

## Tests

GitHub Actions runs Python regressions, JavaScript syntax checks, and a Node-based browser-card simulation exercising preview, confirmation, source invalidation, and single-attempt behavior.
